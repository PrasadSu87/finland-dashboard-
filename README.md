# 🇫🇮 Finland Regional Intelligence Dashboard

A fully interactive regional dashboard built entirely with Claude AI.
No manual coding. No CSV downloads. Just a conversation.

## 🔗 Live Demo
**[View Dashboard](https://PrasadSu87.github.io/finland-dashboard-)**

## 📊 What it shows
- Population, GDP per capita, unemployment for all 19 Finnish regions
- Interactive NLS Finland 2023 boundary map — click any region
- Live weather updates per regional capital city
- Climate data, forest cover, tourism index
- 10-year national trend sparklines on scorecards

## 🗂️ Data Sources
| Data | Source | Year |
|---|---|---|
| Population | Statistics Finland (stat.fi) | 2024 |
| GDP per capita | Eurostat nama_10r_2gdp | 2022 |
| Unemployment | Statistics Finland LFS | 2025 |
| Climate normals | Finnish Meteorological Institute (FMI) | 1991–2020 |
| Live weather | Open-Meteo API (free, no key) | Live |
| Map boundaries | National Land Survey of Finland (NLS) | 2023 |

## 🛠️ Built with
- **Claude AI** — data sourcing, dashboard design, code generation
- **D3.js** — real GeoJSON map rendering
- **Chart.js** — all charts and visualisations
- **Open-Meteo API** — live weather per region
- **GitHub Pages** — free hosting

## 💡 How it was built
1. Asked Claude what data sources to use — got official government APIs instantly
2. Described the dashboard layout and interactions to Claude
3. Claude built the complete interactive HTML dashboard
4. Hosted on GitHub Pages in 5 minutes

> One person. One afternoon. Zero cost.
